# Hirely

AI-powered CV analyzer — an early-stage capstone project.

## Overview

Hirely is being built to help users analyze and improve their CVs using AI. The repository is in active development; features and architecture are still being defined.

## Tech Stack

- **Next.js** — React framework for the web application
- **TypeScript** — typed JavaScript across the codebase
- **Tailwind CSS** — utility-first styling

## Project Status

Early development. The codebase is not yet set up for local installation or deployment.
