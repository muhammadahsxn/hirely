# Hirely — Product Scope

## Product Vision

Hirely is an AI-powered CV analyzer that extracts structured information from a user's CV and provides a detailed, reasonable analysis to help the user understand and improve their CV.

## Target User

Job seekers, particularly students, graduates, and professionals who want actionable feedback on their CV.

## MVP Goal

The MVP will allow a registered user to upload a CV, have Hirely extract and analyze its contents using AI, view detailed results, and access previous analyses.

## Core User Flow

Landing Page
→ Sign Up / Login
→ Dashboard
→ Upload CV
→ Extract CV Data
→ AI Analysis
→ View Results
→ Save Analysis
→ History

## MVP Features

### 1. Authentication
- User registration
- User login/logout
- Session management
- Account management

### 2. CV Management
- Upload PDF/DOCX CV
- File validation
- CV text extraction
- Structured CV data extraction
- Secure storage

### 3. AI Analysis
- Overall CV assessment
- Score breakdown
- Section-by-section analysis
- Strengths
- Weaknesses
- Skills analysis
- Actionable recommendations

### 4. Analysis History
- Store completed analyses
- View previous analyses
- View analysis metadata

### 5. Settings
- Account settings
- User preferences
- Appearance
- Privacy and data controls

## Out of Scope for MVP

- CV editor
- Cover-letter generator
- Job application tracking
- Resume templates
- Social login
- Advanced analytics
- CV comparison
- Payments/subscriptions

## Future Possibilities

Features outside the MVP may be evaluated after the core product is stable, based on user needs and project scope.
